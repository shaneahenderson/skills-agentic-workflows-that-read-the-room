## Awesome Copilot workflows to try

- **Daily Issues Report** — A scheduled workflow that opens a daily issue summarizing new activity, closures, and stale issues, so teams can triage faster.
  Source: https://github.com/github/awesome-copilot/blob/main/workflows/daily-issues-report.md
- **Relevance Check** — A `/relevance-check` slash command that has Copilot evaluate whether an issue or pull request is still relevant, helping maintainers keep backlogs tidy.
  Source: https://github.com/github/awesome-copilot/blob/main/workflows/relevance-check.md
